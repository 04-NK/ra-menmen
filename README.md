- **[旅行サポートアプリ]** です。
- これは **[ホテル近場で安く長く楽しめる観光地を見つけること]** ができ、
- **[Google Map]** とは違って、
- **[安く長く楽しめる観光地・お店のみをシンプルに閲覧できる]** が備わっている。
