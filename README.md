## エレベーターピッチ

- **[フェスやライブ以外も楽しみたい]** したい、
- **[都心に来た旅行者]** 向けの、
- **[ヨリタビ]** というプロダクトは、
- **[旅行サポートアプリ]** です。
- これは **[ホテル近場で安く長く楽しめる観光地を見つけること]** ができ、
- **[Google Map]** とは違って、
- **[安く長く楽しめる観光地・お店のみをシンプルに閲覧できる]** が備わっている。

## 開発環境
- **フロントエンド** : html , css , Leaflet , JavaScript
- **バックエンド** : flask
- **タスク管理** : GitHub
- **マップ** : OpenStreetMap , Leaflet
- **距離計算** : OSRM
