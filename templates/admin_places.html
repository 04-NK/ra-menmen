入力ルール

  • JSONファイルは1MB以下、一度に100件まで登録できます。
  • 全体は {"places": [...]} または場所の配列 [...] にします。
  • 必須項目は name、category、latitude、longitude です。
name 必須
文字列。空文字は登録できません。
category 必須
文字列。下に表示されているDB用の値から指定します。
latitude 必須
数値。-90以上90以下。
longitude 必須
数値。-180以上180以下。
description / address
文字列。未設定は省略または null。
opening_hours
曜日ごとのオブジェクト。キーは monday 〜 sunday を使い、各曜日に最大10件の時間帯を登録できます。
open / close
HH:MM 形式の時刻。複数時間帯は配列、定休日は null、曜日の省略は未設定です。
price_min / price_max
0以上の整数。未設定は省略または null。最高価格は最低価格以上にします。
website_url / source_url
http:// または https:// から始まるURL。未設定は省略または null。
last_verified_at
YYYY-MM-DD 形式の日付。未設定は省略または null。
is_published
true または false。省略した場合は false。
